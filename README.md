Punyakoti Oyster Mushroom Website

A mobile-first product website created for **Punyakoti Traders**, a business dealing with fresh Oyster Mushrooms.

This website is designed primarily for customers who scan a **QR code printed on the mushroom packaging**.
The QR code can take customers directly to the website, where they can learn about Oyster Mushrooms, their nutritional value, cultivation journey, recipes, and the business.

About the Project

This project was developed as a personal web-development project for a friend's business.

The goal was to create a simple, attractive, and informative digital experience that customers can access directly from their mobile phones.

Instead of creating a traditional business website with many pages, the project uses a **single-page mobile-first design** so customers can quickly browse the information after scanning the QR code.
